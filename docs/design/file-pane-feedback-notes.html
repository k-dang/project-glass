    What the flow adds

    • To leave a Feedback note, select text in the page, or turn on Pick element and click any part of it. Selecting text needs no mode.
    • Notes wait above the composer, just like notes on Changes, and go with your next message. You can send them without writing anything.
    • The pane reloads when the agent rewrites the file. Notes you haven't sent follow their text to the new version. If a note's spot is gone, it stays in the composer and says so. To see this, add a note while the agent is working.

    How it would be built

    • The page stays in today's sandboxed iframe. A small script that Glass adds to the page reports the selection and the hovered element to Glass by postMessage.
    • Glass draws the pins, outlines and note editor itself, over the iframe, so the page's own styles can't break them.
    • Each note reaches the agent as a feedback_note inside the glass_feedback block that notes on Changes already use. It carries the file, a selector, the nearest heading and the text it was left on. Open "What the agent reads" on a sent message to see it.

    Decided

    • Pick element stays on until you press Esc or turn it off.
    • Notes leave the page as soon as they're sent. After that they live on the sent message.
    • With Pick element on, clicks go to Glass; with it off, they go to the page's own buttons and forms.
